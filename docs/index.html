Peero

Two devices open the app on the same network, find each other on their own, and exchange text, voice messages and files. No cloud, no sign-up, no phone number.

Install

One command, or the manual steps if you would rather not run a script sight unseen.

One command

curl -fsSL https://peero-app.github.io/peero/install.sh | bash

On Ubuntu/Debian this installs a .deb package through apt. On other distributions it downloads an AppImage into ~/.local/bin.

Manually

  • Ubuntu / Debian — download peero.deb from the releases page, then run: sudo apt install ./peero.deb
  • Other distributions — download peero.AppImage, make it executable (chmod +x peero.AppImage) and run it directly.

With Homebrew

brew install --cask peero-app/tap/peero

Or in one command

curl -fsSL https://peero-app.github.io/peero/install.sh | bash

The app is not signed by Apple. The first time you launch it, if macOS refuses to open it: right-click the app → Open, or run xattr -cr /Applications/peero.app.

One command (PowerShell)

powershell -c "irm https://peero-app.github.io/peero/install.ps1 | iex"

Manually

  • Download peero-setup.exe from the releases page
  • Double-click it and follow the installer

Uninstall

Nothing hidden to hunt down — each install method has its own removal command.

Ubuntu / Debian (.deb)

sudo apt remove peero

AppImage

Just delete ~/.local/bin/peero.AppImage

macOS (Homebrew)

brew uninstall --cask peero
brew untap peero-app/tap

Windows

Settings → Apps, or run unins000.exe in the install folder.
